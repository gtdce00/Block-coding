HOW TO PLAY

วิธีเล่น

ควบคุม Robot

  • W เดินหน้า S ถอยหลัง
  • A ซ้าย D ขวา
  • Shift วิ่ง Space กระโดด
  • E โต้ตอบ / เปิดสมบัติ
  • คลิกหน้าจอหนึ่งครั้งเพื่อล็อกกล้อง แล้วเลื่อนเมาส์เพื่อหันมุมมอง
  • เดินหน้า กล้องจะตามหลังตัวละครเมื่อไม่ได้ล็อกเมาส์
  • Esc ปลดล็อกกล้องและหยุดชั่วคราว

ภารกิจ

  • เดินตามทางดินในป่า หาแสงทองจากกล่องสมบัติ
  • ดูเข็มทิศและดาวทองบนแผนที่มุมขวา
  • เข้าใกล้สมบัติแล้วกด E
  • เรียง Block Coding แล้วกด RUN CODE
  • ถ้าผิด จะบอกว่าติดตรงไหน ให้ลองใหม่ — ครูเปิดเฉลยได้ที่ตั้งค่า
  • ไม่ลด HP และไม่ Game Over
  • เก็บสมบัติครบ 3 ชิ้นต่อโลก เพื่อเปิด Portal
  • มอนสเตอร์ในป่าจะไล่และผลักได้ แต่ไม่ลด HP
  • กระโดดลงบนหัวมอนสเตอร์เพื่อปราบ (+40 คะแนน)
  • โลกสุดท้ายมีบอส ผู้พิทักษ์ป่าโบราณ — กระโดด 3 ครั้งให้เซ็ง แล้วกด E เขียนโค้ด
  • แต่ละด่านมีเวลา 50 นาที (ตั้งค่าได้) เข้าด่านใหม่แล้วนาฬิกาเริ่มใหม่
  • แข่งกับเวลา และขึ้น Leaderboard
